# 靈獸機台 Spirit Beast Arcade（網頁版）

原創機台型「捕捉＋對戰」遊戲（Godot 4.7）：連打按鈕搶先攻、停輪盤會心一擊、集滿必殺技、停晶球輪盤捕捉 27 隻原創靈獸，收集晶片升級。
參考機台捕捉對戰遊戲的玩法類型；靈獸、名稱與美術全部原創。

**開始玩**：https://kevinchang0531.github.io/spirit-arcade/

- 操作：滑鼠點紅色按鈕或按空白鍵；同機雙人用 A 鍵／L 鍵
- 進度（代幣、晶片、圖鑑、戰績）存在瀏覽器，同一台電腦、同一個瀏覽器下次可接著玩
- 連線對戰需要桌面版（瀏覽器不支援直接連線）；網頁版可用同機雙人對戰
- 美術：OpenAI gpt-image-2 生成；音效音樂：程式合成
